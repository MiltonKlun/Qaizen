# BUG-001

## Summary

A locked account can log in through the API: POST /api/login answers 200 instead of rejecting it with 403.

## Severity

red

## Linked Story

STORY-001

## Linked Failure

FAIL-001

## Linked Risk

RISK-002

## Steps to Reproduce

1. Use an account that is locked.
2. POST its valid credentials to /api/login.
3. Read the status code.

## Expected Behavior

The request is rejected with 403 and the account stays locked out.

## Actual Behavior

The request returns 200 (`locked account gets 403: expected 200 to equal 403`).
